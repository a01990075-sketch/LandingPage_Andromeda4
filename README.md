# Andrómeda 4 · Landing del Equipo 4

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `equipo4`).
2. Sube TODO el contenido de esta carpeta (no la carpeta contenedora): `index.html`, `css/`, `js/`, `assets/`.
3. Ve a **Settings → Pages**, en *Source* elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
4. En 1 o 2 minutos tu sitio estará en `https://TU-USUARIO.github.io/equipo4/`.

## Qué editar
En `index.html` busca los comentarios `EDITA AQUÍ`: descripción del proyecto, nombres de integrantes y enlaces de entrega.
La fecha del cronómetro está en `js/main.js` (30 de noviembre, 23:59:59).
